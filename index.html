Web Serial Terminal

Raw serial console via Web Serial API — Chrome / Edge

Supported
chips
Gen-1 UK524-CDC2I2C UK527-WEB2I2C UK529-USB2WST
Gen-2 UK550-WST2MOD UK551-WST21WR UK554-WST2SPI Flash Gen UK557-WST2I2C EEPROM Gen
Disconnected
Ctrl+A+C copy  ·  Ctrl+A+V paste
Web Serial API is not available in this browser. Use Google Chrome or Microsoft Edge (v89+), opened via https:// or localhost. If the API is missing, enable Experimental Web Platform features at chrome://flags/. The interface below still renders, but connecting is disabled.

Keyboard

Press Ctrl+A then C to copy and Ctrl+A then V to paste inside the terminal.
